5-Minute GitHub Setup (Copy & Paste)

1 Create GitHub Repo & Upload index.html

On GitHub, click + → New repository, name it tradepulse, select Public, check Add a README file, and click Create repository. Click Download index.html above, then click Add file → Upload files in your repo and commit index.html.

2 Create new file named watchlist.txt

Auto-filled from your Running Trades & journal symbols. Add new NSE stock symbols here whenever you buy them.

3 Create new file named scripts/fetch_eod.py

Typing / in GitHub's filename box automatically creates the scripts folder.

4 Create new file named .github/workflows/eod-sync.yml

Runs automatically Mon–Fri at 4:05 PM IST after NSE closes and saves data/eod_prices.json.

5 Turn On Your Live Site & Run First Sync
  • Go to Actions → Fetch EOD Stock Prices for TradePulse → Run workflow to generate your first data/eod_prices.json.
  • Go to Settings → Pages → set Branch to main & folder / (root) → click Save.
  • Open https://YOUR-USERNAME.github.io/tradepulse/ — your trades stay private in your browser while EOD prices & real daily candles auto-update every evening!
